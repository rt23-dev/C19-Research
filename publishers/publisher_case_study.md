# Publisher Case-Study Matrix

Last updated: 2026-05-04

## Purpose

This file organizes the main publishers in the translation-factory project into a comparative matrix. It is meant to support case-study writing, archival follow-up, and argument development by showing, at a glance, what kind of evidence exists for each firm and what still needs to be verified.

## How to read this matrix

- `Status in project` means how central the firm currently is to the argument.
- `Evidence type` distinguishes between direct primary evidence, strong scholarly reconstruction, and weaker or more tentative leads.
- `Next step` identifies the most useful research move for that publisher.

## Suggested case-study tiers

### Tier 1: strongest full cases

- Schumann
- Franckh

These are the firms most likely to carry the main German narrative.

### Tier 2: strongest expansion cases

- Kollmann
- Metzler
- Vieweg

These firms are the best next layer because they add complexity:

- Kollmann complicates the blacklist model
- Metzler gives explicit machine-language evidence
- Vieweg offers the strongest archive path

### Tier 3: broader field / support cases

- J. J. Weber
- Reclam
- Westermann
- Meyer senior
- Mayer
- Hartleben

These help show that `Uebersetzungsfabrik` was a field phenomenon, not only a Schumann/Franckh story.
